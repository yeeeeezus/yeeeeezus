### 🛠 how i work

- **root cause first** — i don't patch symptoms; i read the code until the bug explains itself
- **smallest safe diff** — if my PR is big, i did something wrong
- **tests green before submit** — the repo's own suite, plus targeted checks for the fix
- **no drive-by comments** — if i claim a bounty, i ship it or i release it
- **every claim is logged** — publicly, in the ledger above, validated by CI
