### Hi, I'm yeeeeezus

I'm a software developer working on developer tools, security tooling and open source. I write mostly TypeScript and Python, and I like tools that run entirely in the browser — no signup, no tracking, no backend.

- [ai-lab](https://github.com/yeeeeezus/ai-lab) — real text generation (SmolLM2, Qwen 0.5B) plus sentiment and NER running in your browser on your own hardware: [live](https://yeeeeezus.github.io/ai-lab/) · also a [Hugging Face Space](https://huggingface.co/spaces/yeeeeezus/ai-lab)
- [embed-lab](https://github.com/yeeeeezus/embed-lab) — local-only semantic search: paste your notes, ask in plain words, meaning-ranked results, nothing leaves the page: [live](https://yeeeeezus.github.io/embed-lab/)
- [prompt-lab](https://github.com/yeeeeezus/prompt-lab) — structured prompt builder for image, video, world-action and frontier chat models: [live](https://yeeeeezus.github.io/prompt-lab/)
- [tts-lab](https://github.com/yeeeeezus/tts-lab) — a studio for the speech synthesis already inside your browser: voice tuning, live word highlighting, copyable recipe: [live](https://yeeeeezus.github.io/tts-lab/)
- [mcp-dns](https://github.com/yeeeeezus/mcp-dns) — MCP server that gives AI agents typed DNS tools (A, MX, TXT, PTR and more); there's a zero-install [browser playground](https://yeeeeezus.github.io/mcp-dns/) too
- [portprobe](https://github.com/yeeeeezus/portprobe) — zero-dependency async TCP port scanner for Python: banner grabbing, closed/filtered classification, JSON output
- [pass-guard](https://github.com/yeeeeezus/pass-guard) — password strength and breach check that never sends your password anywhere: [live](https://yeeeeezus.github.io/pass-guard/)
- [gradient-studio](https://github.com/yeeeeezus/gradient-studio) — CSS gradient generator, one static file, zero dependencies: [live](https://yeeeeezus.github.io/gradient-studio/)
