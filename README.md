### `cat rules.txt`

- **root cause first** — i don't patch symptoms. i read the code until the bug explains itself.
- **smallest safe diff** — if my PR is big, i did something wrong.
- **tests green before submit** — the repo's own suite, plus targeted checks written for the fix.
- **no drive-by claims** — if i take a bounty, i ship it or i release it publicly.
- **every claim is logged** — in the ledger, validated by CI. estimates labeled as estimates. paid means paid.
- **authorized targets only** — bug bounties and OSS. nothing else. ever.
